# Aleena Shafiq — Modern Premium Portfolio

A complete, modern, premium, and highly professional personal portfolio website designed for **Aleena Shafiq**, a **Frontend Developer & UI/UX Designer**, crafted with a dark futuristic developer aesthetic.

---

## 🎨 Visual Identity & Theme Architecture

The website implements a high-end futuristic design language featuring:
* **Primary Deep Black/Navy Canvas**: `#030015` with secondary depth `#080025`
* **Atmospheric Glow Accents**:
  * Electric Purple (`#713CFF`)
  * Deep Purple (`#24105A`) & Purple Glow (`#5B2EFF`)
  * Electric Blue (`#3478FF`) & True Blue (`#245CFF`)
  * Cyan Neon Highlights (`#00BFFF`)
* **Glassmorphism System**: Multi-layered cards with backdrop blur (`backdrop-filter: blur(16px)`), subtle `1px` translucent borders, and soft radial lighting.
* **Subtle Cyber Grid & Stardust Particles**: Low-opacity 64px developer coordinate grid combined with an interactive HTML5 canvas particle starfield.
* **Modern Typography**:
  * **Headings**: *Space Grotesk* (futuristic, bold, sharp)
  * **Body Copy**: *Inter* (clean, ultra-legible)
  * **Code & Badges**: *Fira Code* (monospace developer aesthetic)
